# Next Components Styling

Laboratorio 11: ejemplos de componentes reutilizables con CSS Modules y Tailwind CSS.

## Requisitos

- Node.js 20.9 o superior

## Instalación y ejecución

```bash
npm install
npm run dev
```

Abre http://localhost:3000. La página principal redirige al ejercicio en `/styling`.

## Contenido

- Variantes de botones estilizadas con CSS Modules.
- Tarjetas de contenido para practicar composición y estilos.
- Tailwind CSS para los estilos globales, separado de los módulos CSS.
