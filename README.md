# Laboratorio 11: Componentes y Estilización

**Autor: Harold Salvador Zarate**

Este repositorio contiene los dos proyectos del laboratorio:

1. [`next-components-styling`](./next-components-styling/README.md): componentes React, CSS Modules y Tailwind CSS.
2. [`next-shadcn-ui`](./next-shadcn-ui/README.md): dashboard de proyectos con Next.js, TypeScript y shadcn/ui.

## Ejecutar los proyectos

Cada carpeta es una aplicación independiente. Desde la carpeta que quieras probar:

```bash
npm install
npm run dev
```

- Para el primer proyecto, abre http://localhost:3000; se redirige a `/styling`.
- Para el dashboard, abre http://localhost:3000/dashboard.

Si ejecutas ambas aplicaciones a la vez, inicia una de ellas en otro puerto, por ejemplo `npm run dev -- --port 3001`.
